ECG AND PPG SIGNAL PROCESSING
This project analyzes ECG and PPG signals to calculate heart rate in MATLAB using the Pan-Tompkins algorithm.
IMPORTANT:
To run the scripts, the signal data files (.mat) MUST be saved in the same folder as the .m files.
HOW TO RUN IN MATLAB:

1. Place the data files in this same folder.
2. Open MATLAB in this directory.
3. Run the script you wish to test:
   - PanTompkins.m (Pan-Tompkins algorithm)

FILES:
- PanTompkins.m: QRS peak detection at 1000 Hz and BPM calculation.PROCESAMIENTO DE SEÑALES ECG Y PPG

   - PanTompkins.m (Algoritmo Pan-Tompkins)
